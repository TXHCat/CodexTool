# LXH Pet Example

This directory contains a complete Codex pet package assembled from the
categorized sprite frames in `I:\LXH\sprite`.

Files:

- `pet.json` - Codex pet manifest.
- `spritesheet.webp` - 1536x1872 WebP atlas, 8 columns by 9 rows, 192x208 cells.
- `validation.json` - `validate_atlas.py` output for the atlas.

To install this example locally, copy the directory to:

```text
%USERPROFILE%\.codex\pets\lxh
```
