# Project Harness

This directory maintains two components:

- [Project Map](HCA_PROJECT_MAP.md): a derived locator of authoritative files, ownership boundaries, module dependencies, entry points, and verification routes.
- [Error Ledger](ERROR_LEDGER.md): reusable failure-prevention guidance, with [active patterns](error-ledger/PATTERNS.md), a searchable [catalog](error-ledger/CATALOG.md), and canonical incidents under `error-ledger/entries/`.

Follow [AGENTS.md](AGENTS.md) for maintenance rules. Update the Map when locations or module/ownership topology change. Add an incident only when it contributes distinct reusable prevention information.

Project execution, delegation, Review, and verification are governed by the root [AGENTS.md](../AGENTS.md) and owning workflows.
