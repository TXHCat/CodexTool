# Active Error Prevention Patterns

These patterns are the default prevention surface. Search them before opening incident records; representative incidents remain evidence, not current project authority.

## Rules

- Add or revise a pattern only when retained incident evidence supports a reusable cross-task prevention rule.
- Keep triggers, rules, and search terms concise and stable.
- Link only retained canonical incidents as representative evidence.
- An exact repeat updates the matching pattern and current task records without allocating a new incident ID.
- Removing a representative incident requires checking and repairing every affected pattern link.

## Pattern Template

```text
## PAT-001 — Short prevention title

- Trigger: Conditions that make this pattern relevant.
- Rule: The default prevention behavior.
- Search terms: `stable retrieval terms`.
- Representative incidents: [ERR-0001](entries/ERR-0001-0025.md#err-0001).
```
